# Spellwire

A top-down survivor roguelite where you build your weapon from a trigger, a modifier and an elemental payload, then watch how each part changes the way it fires.

**Status:** pre-development. The design and development plan are approved; the first playable milestone (M0) has not started yet. There is nothing to play yet.

- [Product specification](docs/spec.md)
- [Development plan](docs/plan.md)
- [Decision log](docs/decisions.md)
- [Current status](docs/status.md)

Planned stack: TypeScript, Phaser 3 and Vite, deployed to GitHub Pages.
